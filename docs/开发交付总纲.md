## 开发 AI 的最高优先级指令

这是一个全新重构项目。不得复制原项目代码、目录结构、旧数据库、旧接口、旧路由或旧页面，只能参考业务含义。

## 一级菜单硬约束

只有四个一级菜单：

- 工作台
- 家庭台账
- 洞察
- 设置

登录和首次启动引导属于系统入口，不计入业务一级菜单。资产、账户、流水、负债、信用卡、投资、房产租赁、对账、智能录入、提醒均属于家庭台账内部页面或抽屉。AI 是全局能力，不是独立菜单。

## 明确不建设

盘点、后台任务系统、Worker、消息队列、导出功能、位置管理、云端 AI 默认外发、AI 未确认直接写正式业务数据。

## 全局体验硬约束

支持浅色/深色模式切换并记忆用户选择；用户界面、字段、按钮、状态、错误和提示全部使用中文；日志必须记录完整明细和变更前后差异；任何删除或不可逆操作必须二次确认；所有弹窗使用统一组件、尺寸、层级、按钮顺序和关闭规则；必须支持数据备份恢复、数据质量检查、多币种底层预留、版本升级和模块化验收。

## 目标技术基线

Vue 3 + TypeScript + Vite + Vue Router + Pinia；图表使用 ECharts；后端使用 FastAPI + Pydantic + SQLAlchemy 2.x；MySQL 8.x；Alembic；本地 AI 采用 OpenAI 兼容接口或 Ollama 适配器；通知采用可插拔 PushPlus 适配器。
