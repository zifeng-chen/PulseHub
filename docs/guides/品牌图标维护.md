# 品牌图标维护说明

账户卡片左上角的机构标志来自 `frontend/public/brands/`，由 `frontend/src/components/ui/BrandIcon.vue` 按机构名匹配。本页说明图标从哪来、怎么加新的一家。

## 一、数据源

| 用途 | 地址 |
|---|---|
| 图标集合页面（人工浏览、看新图标） | <https://www.iconfont.cn/collections/detail?cid=23316> |
| 数据接口（脚本用，直接返回 SVG 源码） | <https://www.iconfont.cn/api/collection/detail.json?id=23316> |

- 集合名：**银行LOGO合集**；作者：小白大志（iconfont 个人用户，非官方）
- 规模：610 个 = 301 个纯 logo + 303 个「组合」款 + 少量监管/机构标志
- 页面是 Vue 单页应用，**直接抓 HTML 只有标题**，必须走上面那个接口取 `icons[].show_svg`

> 许可提醒：iconfont 该集合的 `license` / `copyright` 字段为空，图标本身是各家银行的商标。
> 自用（识别账户）没问题；本仓库是公开仓库，所以只导入项目真正用到的那几家，
> 不做整体搬运。新增图标前先确认这家机构确实会被用到。

## 二、现有约定

1. **只取纯 logo，不要「组合」**。组合款是「logo + 中文字标」的横版，塞进 60×36 的卡片框字会糊。
   脚本按名字过滤：含 `（组合）` 的一律丢弃。
2. **只取项目需要的银行**。映射表在 `deploy/import_brand_icons.py::BANK_ICONS`，
   key 与 `BrandIcon.vue` 里的 `BRANDS[].key` 一一对应。
3. **两个例外不替换**（脚本 `SKIP_KEYS` 已默认跳过）：
   - `ceb` 光大：集合里是 "Everbright Bank" 英文文字标，宽高比 2.5:1，小尺寸认不出；
   - `pab` 平安：集合里是「中国平安」橙色组合框，含中文且过密。
4. **支付平台不在这个集合里**（支付宝、微信支付、云闪付、美团、抖音仍是 PNG），别在这里找。

## 三、新增一家银行

以「浙商银行」为例：

```bash
# 1) 先在映射表里加一行：key 用 BrandIcon 里的命名，值写集合里的图标全名
#    "czbank": "浙商银行logo",
#    然后导入（--only 只导这一家）
python deploy/import_brand_icons.py --only czbank --out .tmp/preview

# 2) 看一眼再落库（图标是否过小 / 是否文字标 / 是否裁切）
python deploy/import_brand_icons.py --only czbank --out frontend/public/brands
```

```ts
// 3) frontend/src/components/ui/BrandIcon.vue —— 补一条映射（别名宁多勿少）
{ key: 'czbank', file: 'czbank.svg', color: '#C70010', aliases: ['浙商银行', '浙商', 'czbank'] },
```

4. 本地 `npx vite build` 后打开「账户」页确认图标能显示（`BrandIcon` 加载失败会自动回退首字标，不会破图）。

### 关于 viewBox

iconfont 的 logo 只占 1024 画布约 66%，直接当 `<img>` 用会显得很小。导入后需要把
`viewBox` 收紧到内容边界 + 3% 留白：

1. 把该 SVG 放进浏览器页面，对 `<svg>` 调 `getBBox()` 拿到 `{x, y, width, height}`；
2. `viewBox = "{x-pad} {y-pad} {w+2pad} {h+2pad}"`，`pad = max(w,h) × 0.03`；
3. 只改 `viewBox`，其余路径不动。

`deploy/import_brand_icons.py` 只做「拉取 + 去白底 + 统一根标签」，**不负责收紧**（需要浏览器量边界），
所以重新导入会回到 1024 画布，记得再收紧一次。

## 四、两个容易踩的坑

- **白底方块**：每个图标自带一个 1024 的白色圆角方块（`fill="#FFFFFF"`，圆角 224/223）。
  必须只删第一个这种 path，白色细节（如上海银行 logo 里的白线条）要保留，删错会破图。
- **删文件要清远端**：部署是 tar 覆盖式解包，本地删掉/改名的图标会残留在 NAS 源码目录并被
  打进镜像（曾出现 `ccb.png` 与 `ccb.svg` 同时存在）。`deploy/nas_deploy.py` 现已在解包前
  清空 `frontend/public` 与 `frontend/src`，改这块时别把这行删掉。
