# FAM V2.1 本地启动说明（M0 框架基座）

> 产品与技术契约以 `docs/spec/` 下 00–24 号文档为准；本文件只说明如何把基座跑起来。

## 目录结构

```text
V2.1版本/
├─ docs/spec/00-…-24-…      产品与交付规范（只读，不改动）
├─ docs/reports/            模块交付报告与审查结论
├─ docs/guides/             本文件与备份恢复说明
├─ backend/                后端（FastAPI + SQLAlchemy 2.x Async + Alembic）
└─ frontend/               前端（Vue 3 + TS + Vite + Pinia + Vue Router + ECharts）
```

## 依赖环境

- Python 3.13（建议在 `backend/.venv` 建独立虚拟环境，下文的 `<venv>` 指该环境）
- Node.js 22（npm 10）
- 数据库：生产与首次启动向导固定 **MySQL 8.x**；本地开发与自动化测试默认使用 **SQLite** 作为可运行底座（本机无 MySQL 与 Docker 时的既定方案，见 M0 交付报告 §16.1）

## 启动后端

```bash
cd backend

# 首次准备（已执行过一次即可跳过）
python -m venv <venv>            # 或使用已有虚拟环境
<venv>/pip install -r requirements.txt

# 环境变量（本地开发）
export FAM_APP_ENV=development
export FAM_DATABASE_URL="sqlite+aiosqlite:///./data/fam_dev.db"

<venv>/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- 接口文档：http://127.0.0.1:8000/docs （仅非生产环境开放）
- 健康检查：http://127.0.0.1:8000/api/v1/health

### 生产 / MySQL 环境

```bash
export FAM_APP_ENV=production
export FAM_DATABASE_URL="mysql+aiomysql://user:pass@127.0.0.1:3306/fam?charset=utf8mb4"
export FAM_JWT_SECRET="<强随机值>"
export FAM_ENCRYPTION_KEY="<Fernet Key>"
<venv>/python -m alembic upgrade head      # 生产不自动建表，必须走迁移
<venv>/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

> 生产环境必须设置 `FAM_JWT_SECRET` 与 `FAM_ENCRYPTION_KEY`，并且不允许使用"内嵌开发数据库"选项。

## 启动前端

```bash
cd frontend
npm install
npm run dev        # http://127.0.0.1:5173（已配置 /api 代理到 127.0.0.1:8000）
```

其他脚本：

```bash
npm run typecheck  # vue-tsc 类型检查
npm run build      # 生产构建
npm test           # vitest（导航回归等）
```

## 测试

```bash
# 后端单元与接口测试（21 项）
cd backend && <venv>/python -m pytest -q

# 后端端到端验收（56 项，需先启动后端）
cd backend && <venv>/python tests/e2e_m0_acceptance.py

# 前端导航回归（12 项）
cd frontend && npm test
```

> 若本机设置了 `HTTP_PROXY`，本地联调需加 `NO_PROXY=127.0.0.1,localhost`，否则请求会被代理拦截。

## 首次使用

1. 打开 http://127.0.0.1:5173/ → 自动跳转 `/setup/check`。
2. 安装检测通过后进入 `/setup`，按六步完成：数据库连接 → 管理员 → 家庭基础信息 → 财务口径 → 接入配置（可全部跳过）→ 完成。
3. 完成后公开初始化接口关闭，跳转 `/login` 登录。
4. 首次登录后在 `/dashboard` 显示一次性欢迎引导（关闭后不再出现）。

本地开发数据库的演示账号为首次启动引导中创建的账号（示例：`admin`）。

## M0 之后的模块顺序（不得跳序）

```text
M1 核心账务 → M2 资产与专项资产 → M3 负债与信用卡 + 投资
→ M4 房产租赁 + 对账 → M5 智能录入 + OCR → M6 工作台 + 洞察
→ M7 本地 AI + 第三方 AI → M8 提醒 + PushPlus + 最终安全验收
```

每个模块必须同时交付：数据库迁移、API、页面、关联关系、AI 接入、错误状态与测试；未验收的模块不得作为已完成继续向后扩展。
