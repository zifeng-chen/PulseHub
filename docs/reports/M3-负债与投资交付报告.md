## 4. 关键口径（后端确定性计算，前端不自行计算）

1. **剩余本金** = 初始金额 + Σ(已确认负债变动 in) − Σ(out)；负债方向语义：`in` = 本金增加（借款到账、信用卡消费），`out` = 本金减少（还款）。
2. **还款拆分**：建议利息 = 剩余本金 × 周期利率（年利率 ÷ 每年期数）；本金 + 利息 + 费用必须等于还款总额；调整必须填原因。
3. **支出只含利息与费用**：本金生成 `liability_repay` 事件（不计支出），利息与费用生成 `expense` 事件（计入支出）——已用测试锁死。
4. **信用卡还款不重复计消费**：消费生成 `expense`（计入支出 + 已用额度增加）；还款只减少已用额度，不再次计入支出。
5. **投资账户余额** = 初始可用资金 − Σ(买入金额+费用) + Σ(卖出金额−费用) + Σ(分红) − Σ(费用)。
6. **持仓按加权平均成本**：成本价 = Σ(买入金额+费用) / Σ(买入数量)；已实现损益 = Σ(卖出净额 − 卖出数量 × 成本价) + 分红 − 费用；未实现损益 = 市值 − 剩余持仓成本。
7. **当前价只来自手工估值**；无估值时按成本展示并标注「仅基于手工估值」，AI 不获取或编造价格。
8. **净资产** = 账户余额 + 资产当前价值 + 投资市值 − 负债剩余本金（仅基础币种展示合计；投资市值受「财务口径 → 投资估值纳入净资产」开关控制）。
9. **多币种**按币种分组，不做跨币种相加。

## 7. AI 上下文与禁止动作（09）

- **负债允许**：说明偿付压力、月供占比与到期日历；解释本金/利息/费用构成；提示即将到期与逾期负债。
- **负债禁止**：自动发起还款或调整还款金额；自动修改剩余本金、利率或还款计划；在没有数据时编造还款能力结论。
- **投资允许**：分析持仓占比、集中度与成本；说明已实现/未实现损益与分红；提示缺少估值或估值过期的持仓。
- **投资禁止**：自动下单或调整持仓；自动获取行情或编造价格；把手工估值当作实时行情。
- 两个详情页均有「AI 分析」页签直接展示上述边界并提供打开面板入口。

## 11. 已知限制与下一模块依赖

1. **对账**依赖 M4（`/ledger/reconciliation` 仍为占位）；**租约/租金/押金**依赖 M4。
2. **分红与费用不生成家庭收支事件**：23 §3 的事件枚举只定义了投资买入/卖出，未定义投资分红，因此分红与费用作为投资账户内部记录（影响账户余额与已实现损益）并写入审计；若后续需要把分红计入家庭收入，属于口径变更，需你确认后调整。
3. **账单到期提醒推送**依赖 M12；当前已实时派生逾期/待还状态。
4. **投资估值仅手工录入**（06 §8 明确「估值可以手工录入」），系统不接行情源、不自动估值。
5. 信用卡「消费明细」按关联事件展示；分类可选，未分类消费会在数据质量模块（M6）提示。
