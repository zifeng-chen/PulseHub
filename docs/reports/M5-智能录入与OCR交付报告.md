## 1. 模块目标与不包含内容

**目标**：材料附件上传（含安全检查）、百度 OCR 识别、结构化结果审核、生成草稿/确认入账、OCR 调用记录与失败重试。

**不包含**（对应后续模块）：
- AI 智能分类/字段补全（智能版结构化）→ M7 本地/第三方 AI；
- 批量数据导入（import_batches/import_records）→ 最终验收阶段（24 §7）；
- 数据质量问题检测 → M6/最终阶段。

## 3. 能力

### 3.1 附件上传（24 §4 附件安全，补齐审计 O2）
- 类型白名单（png/jpg/jpeg/pdf），扩展名 + MIME 双校验，未知格式拒绝；
- 大小限制（默认 20MB）、空文件拒绝；
- SHA256 校验值、按家庭隔离落盘、文件名不暴露原始名；
- 下载/删除前重新校验权限；删除需二次确认令牌 + 原因并写审计。

### 3.2 百度 OCR（10 §5、09 §47）
- `BaiduOcrAdapter.recognize()`：凭证校验 → 通用文字识别 → 返回原文；
- 未配置时 409 降级，前端显示可操作配置入口（不阻塞手工记账）；
- 识别失败记录 `ocr_call_logs`（failed），支持手动重试；
- 调用记录含原文、结构化结果、置信度、耗时、重试次数。

### 3.3 结构化与审核（06 §10、14 §103）
- 简单确定性提取：金额、日期候选，置信度标注；
- **低置信度不默认选中**，用户显式确认后才入账；
- 审核后生成草稿事件（`source=ocr`），确认后经统一资金变动进入统计。

## 4. API（新增 8 条）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/ledger/capture/attachments` | 上传材料（multipart） |
| GET | `/ledger/capture/attachments` | 附件列表 |
| GET | `/ledger/capture/attachments/{id}/download` | 下载（权限重校验） |
| DELETE | `/ledger/capture/attachments/{id}` | 删除（令牌+原因） |
| POST | `/ledger/capture/ocr` | OCR 识别 |
| GET | `/ledger/capture/ocr-logs` | 调用记录 |
| POST | `/ledger/capture/ocr/{log_id}/retry` | 失败重试 |

## 6. 已知限制与下一模块依赖

1. **AI 智能结构化**（分类建议、字段补全、置信度评估）依赖 M7 本地/第三方 AI；当前为确定性正则提取。
2. **真实百度 OCR 调用**需用户在设置中配置 API Key/Secret（当前未配置，测试走降级路径）。
3. **数据质量「疑似重复流水」检测**依赖 M6/最终阶段。
4. 附件与业务对象的深度关联（如资产详情附件页签显示已上传文件）随后续模块逐步接通。
