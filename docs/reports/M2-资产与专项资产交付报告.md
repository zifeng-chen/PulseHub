## 4. 领域服务与事务边界

| 服务 | 职责 |
|---|---|
| `app/services/assets.py` | 资产 CRUD、估值、处置、归档、汇总统计、流动性归类、敏感字段掩码、类型切换校验 |
| `app/services/asset_extensions.py` | 四类扩展表 + 水电煤户号 + 车辆保险的 CRUD 与序列化、关联校验、批量取扩展 |
| `app/services/events.py`（扩展） | `movement_specs()` 推导资金变动：资产购置/处置生成**账户 + 资产双变动**；解锁 asset_acquire/asset_dispose 创建 |
| `app/services/stats.py`（扩展） | 净资产 = 账户余额 + 资产当前价值；资产结构图；净资产趋势并入资产（按估值历史，缺失时用购置成本近似） |

**事务边界**：创建资产（含扩展表写入、初始估值、可选购置事件与资金变动）在同一事务；处置（事件 + 双资金变动 + 状态变更 + 审计）在同一事务；审计与业务写入同事务提交。

**关键口径（不可绕过）**：
1. 净资产只纳入「`include_in_net_worth` 且 未出售/未报废/未归档」的资产当前价值。
2. 已处置资产立即退出净资产；处置收入进入去向账户；处置事件冲销后资产恢复处置前状态（状态取自处置时审计记录的 `before`）。
3. 修改已确认价值必须填写调整原因，并写入估值时间线（口径可追溯）。
4. 已有估值或事件的资产不允许直接切换类型（15 §9）。
5. 多币种按币种分组，不做跨币种相加；顶部统计只展示基础币种并在页面明示。

```
GET    /ledger/assets                   资产列表（筛选 + 顶部统计）
GET    /ledger/assets/summary           资产顶部统计
POST   /ledger/assets                   新增资产（含扩展字段 + 可选购置事件）
GET    /ledger/assets/{id}              资产详情（估值/事件/附件/关联/AI 边界）
PUT    /ledger/assets/{id}              编辑资产（含扩展字段、价值调整原因）
GET    /ledger/assets/real-estates      不动产列表
GET    /ledger/assets/parking-spaces    车位列表
GET    /ledger/assets/vehicles          车辆列表
GET    /ledger/assets/precious-metals    贵金属列表
GET    /ledger/assets/{id}/valuations   估值历史
POST   /ledger/assets/{id}/valuations   新增估值
POST   /ledger/assets/{id}/dispose      处置资产（一次性确认令牌）
POST   /ledger/assets/{id}/archive      归档资产（一次性确认令牌）
GET    /ledger/assets/real-estates/{id}/utility-accounts
POST   /ledger/assets/real-estates/{id}/utility-accounts
PUT    /ledger/assets/utility-accounts/{id}

GET    /ledger/assets/vehicles/{id}/insurances
POST   /ledger/assets/vehicles/{id}/insurances
PUT    /ledger/assets/vehicle-insurances/{id}
DELETE /ledger/assets/vehicle-insurances/{id}
```

## 6. 与已有模块的读写关系

| 关系 | 方向 | 说明 |
|---|---|---|
| 账户 | 读 + 写事件 | 资产购置从账户扣款、处置去向账户入账，全部通过统一业务事件与资金变动 |
| 业务事件 | 写 | asset_acquire / asset_dispose 事件由资产模块创建；通用事件接口也支持创建这两类（强制校验 asset_id） |
| 分类 | 不涉及 | 资产不使用收支分类 |
| 审计 | 写 | asset.create/update/valuation/dispose/archive/dispose_reverted/extension_update、utility.*、insurance.* |
| 统计 | 读 | 统计服务读取资产当前价值与估值历史，前端不计算任何金额 |
| 负债 / 租赁 | 只留关联字段 | `assets.linked_liability_id` + 模块说明空状态 |

## 7. AI 上下文与禁止动作（09）

- **允许**：分析资产占比、价值变化与集中度；提示长期未更新估值的资产；说明资产与关联负债的覆盖关系。
- **禁止（已写入接口返回并由 UI 明示）**：自动修改资产当前价值或新增估值；自动处置、归档或删除资产；在缺少来源与日期时编造参考价格。
- 资产详情页「AI 分析」页签直接展示上述边界，并提供打开全局 AI 面板的入口。

## 11. 已知限制与下一模块依赖

1. **房贷/车贷明细依赖 M3**：本模块只保留标记与关联入口，符合 15 §3.2「不重复录入第二套数据」。
2. **租赁摘要依赖 M4**；**附件上传与 OCR 依赖 M5**；**保险到期推送依赖 M12**。
3. **流动资产口径**：按资产类型推导（贵金属 = 流动资产，其余为非流动），未新增字段以遵守「不得自行增加字段」；该口径已写入接口 `caliber` 字段并在页面展示，后续如需调整只需改一处。
4. **净资产趋势中的资产部分**：按估值历史取值、无估值时用购置成本近似（已在 `caliber` 注明）。
5. NAS 首次初始化向导已完成，登录后即可直接操作资产页面。
