## 1. 登录、安装检测与首次启动引导流程

启动判定（04）：打开系统 → 安装与服务检查 → 三态分支：
- 未初始化 → 首次启动引导 `/setup`
- 已初始化未登录 → 登录页 `/login`
- 已登录 → 应用壳 `/app`

### 1.1 安装检测 `/setup/check`
- 内容：品牌区、系统版本、数据库服务状态、文件权限、后端健康状态、初始化按钮。
- 状态：检测中 / 通过 / 警告 / 失败。失败项显示修复建议 + 重新检测。
- 该页**不需要登录**。

### 1.2 首次启动引导 `/setup`（六步，顶部步骤条 + 右侧说明区，可回退不可跳过数据库与管理员）
1. **数据库连接**：数据库类型固定 MySQL、主机、端口、库名、用户名、密码、SSL 开关、连接超时。测试成功显示延迟 / MySQL 版本 / 可建表权限；成功后创建或校验迁移表，**不导入旧项目表结构**。
2. **创建管理员**：管理员名称、登录账号、密码、确认密码、恢复邮箱或恢复提示；密码实时强度提示；唯一性校验；成功后不可逆提醒 + 账号摘要。
3. **家庭基础信息**：家庭名称、默认时区（Asia/Shanghai）、基础币种（CNY）、家庭描述、是否启用多成员；生成默认家庭、系统分类、基础提醒规则。
4. **财务口径**：资产购置是否独立于消费、默认统计周期、净资产是否含指定资产类型、是否启用投资估值、账单日/还款日显示方式；每项有解释与恢复默认。
5. **接入配置**（三卡独立保存，某项失败不阻塞其他项）：本地 AI（地址/协议/模型/测试，可跳过）、百度 OCR（Key/Secret/测试，凭证掩码）、第三方 AI API（提供商/Base URL/Key/模型/外发策略/测试，**默认关闭**）、PushPlus（Token/开关/测试，默认关闭）。每卡显示"已连接/未配置/测试失败"。
6. **完成页**：管理员、家庭、基础币种、AI/OCR/通知状态摘要；进入登录页 / 查看设置 / 查看使用指南。首次登录后再显示欢迎引导，不重复进入初始化。

### 1.3 登录 `/login`
- 布局：左品牌 + 动态背景，右玻璃登录卡。字段：账号、密码、记住设备、登录按钮；辅助：忘记密码、查看系统状态。
- 状态：初始、输入中、提交中、登录成功、账号不存在、密码错误、账号锁定、服务不可用、初始化未完成。**密码错误不区分账号不存在/密码错误**；连续失败触发短暂锁定。
- 交互：回车提交；提交中按钮进度且不可重复点击；成功卡片缩小淡出、应用壳右侧淡入；失败保留账号、清空密码并聚焦密码框。

### 1.4 忘记/重置密码
本地部署管理员恢复流程：验证管理员恢复方式 → 设新密码 → 失效旧会话 → 写审计。未配置邮箱时提示"管理员在本机执行恢复"，**不伪造外部找回能力**。

### 1.5 首次登录欢迎
进入工作台前一次性欢迎层，三步引导"录入数据—查看台账—让 AI 分析"，含三个入口（新增账户/上传第一张账单/打开 AI 助手），可关闭且不再自动出现。

### 1.6 安全
HTTPS 或本地安全传输；密码强哈希不可逆；会话过期跳登录；记住设备用可撤销刷新令牌；**初始化接口仅在未初始化时开放，完成后关闭公开初始化接口**。

- **负债** `/ledger/liabilities`：列表（债务名称/类型/剩余本金/利率/下次还款日/月应还/状态）；详情页签（概览/还款计划/还款记录/利息费用/关联资产/AI）；还款按本金/利息/费用拆分，手调需说明。

- **投资** `/ledger/investments`：投资账户列表、持仓（标的/数量/成本价/当前价/市值/已实现未实现损益/占比/估值日期）、交易（买/卖/分红/费用）；估值可手工录入；**不下单、不自动估值**。
- **房产租赁** `/ledger/leases`：房产列表引用资产专项**唯一主对象 `real_estates`**（不另建 properties）；租约表单（房产/租客/租期/月租/付款周期/起租到期/押金/收款账户/提醒规则/附件）；详情含应收（**不改账户余额**）、实收（**必须关联到账账户**）、逾期、押金（单独列为待退还）。

## 4. 领域实体、业务事件、资金变动与统计关系

**统一领域链（02 §2）**：家庭 → 成员/账户/资产/负债/投资账户持仓/房产租约/分类/业务事件；业务事件 → 资金变动 → 账户/资产/负债/投资/房产；资产→估值；负债→还款；投资→交易；房产→应收/实收/押金；事件→附件→OCR→AI 建议（用户确认后回到事件）；事件→确定性统计→工作台/洞察/AI。

**资产类型结构（02/15/19）**：资产主表 + 类型扩展表（`real_estates`/`parking_spaces`/`vehicles`/`precious_metals` + 其他资产 JSON 自定义属性，但关键金额/日期/持有人/状态**不得只放 JSON**）+ 关联关系 + 估值历史 + 业务事件。
- 不动产：产权证/不动产权证/地址文本/面积/共有人/共有比例/房贷/出租/水电煤户号；证件号默认掩码。
- 房贷：**必须关联具体不动产**，余额/利息/本金由负债模块管理，资产页只显示摘要 + 跳转，**不重复录第二套数据**。
- 车位：`linked_real_estate_id` 关联一套不动产（一车位≤1 房产，一房产可多车位）；解除关联留审计；车位有独立贷款则关联独立负债，**不能挂到房贷本金**。
- 车辆：VIN/车牌/发动机号掩码；车贷关联车辆+负债两边；多份保险；费用进统一流水并保留 `vehicle_id`。
- 贵金属：品类/形式/纯度/重量/批次/加工费/估值来源；实物价值可"重量×纯度×参考单价"但**参考单价必须标来源与日期**；无行情只用用户手工估值。
- **`real_estates` 是不动产与房产租赁共用的唯一主对象**（19 §5.1，禁止第二套房产主对象）。

**核心口径（01 §4）**：净资产 = 可计入资产当前价值 + 投资当前市值 − 负债未偿余额；收入只含已确认收入/投资收入/租金实收（借款、押金、内部转入**不算**）；支出只含已确认消费/利息/手续费（**信用卡还款与贷款本金不重复计**）；内部转账只改账户余额；资产购置形成资产+资金减少，是否计消费由事件口径显示区分、**不得双计**；应收/计划/账单/草稿 ≠ 实际发生；多币种按币种分组，**须用户确认汇率和换算规则后**才生成换算结果。

**业务事件状态机（11 §2）**：`draft -> confirmed -> reversed` 或 `draft -> cancelled`；确认后不可直接改关键金额，只能冲销/更正。**草稿不进入**余额、净资产、收支、洞察或 AI 权威分析（23 §4）。确认事件必须在**同一事务**中生成资金变动与审计记录。

**其他状态机**：AI 建议 `pending -> accepted/rejected/expired`（终态不可重复操作）；资产 `active -> disposed/archived`；负债 `active -> overdue -> settled`；租约 `draft -> active -> expired/terminated`；提醒 `pending -> completed/snoozed/dismissed`；通知发送 `pending/sent/failed`（**不是后台任务**）；文件 `uploaded -> scanning -> ready/failed`。

**统计契约（23 §10）**：统计接口接收期间/币种/成员范围/是否含草稿（默认否）/数据版本；返回统计口径、参与记录数、排除记录数、数据质量提示、更新时间。**前端不自行计算**净资产、余额、损益或汇总金额。

### 5.3 权限（23 §6、10 §6）
权限拆成 **10 类动作**：查看、创建草稿、编辑草稿、确认、冲销、更正、归档、删除、配置、审计查看。角色只拥有**动作集合**，成员范围再限制**对象范围**。后端每次请求同时校验 用户 + 家庭 + 对象 + 动作 + 成员/资产范围。四类用户：系统管理员 / 家庭所有者 / 家庭成员 / 只读成员。

### 5.4 事务与幂等（10 §6、11 §4）
确认业务事件、转账、还款、接受 AI 建议、创建通知记录**必须事务化并支持幂等键**；源数据版本变化返回 **409** 并要求刷新；所有列表查询带家庭与权限范围。防重复：按钮提交期锁定 + 服务端幂等键 + 刷新不重复创建 + 接受建议前检查状态 + 批量逐项返回。

**错误码映射（11 §3）**：401→登录、403→权限范围、404→对象不存在、409→数据已变化、422→字段错误、429→稍后重试。

## 6. 本地 AI / 百度 OCR / PushPlus 接入位置与失败降级

**调用优先级（09 §5.1、14 §4）**：权限检查 → 确定性工具 → 本地 AI → 可选第三方 AI。第三方 AI **仅当**设置中显式启用 + 隐私策略允许 + 外发预览通过 + 写入审计后才可调用。**任何模型都不能绕过确定性统计工具自行计算权威金额**，本地 AI 失败**不能静默切换**第三方。

- **本地 AI**：接入点 = 设置/本地 AI（协议/地址/模型/Key/超时/上下文长度/流式/启用）+ 全局 AI 侧栏（宽 420px）+ 各页面 AI 入口 + 智能录入 + 洞察报告。默认不连云端。状态：未配置/检测中/已连接/模型不可用/权限失败/超时。降级：模型断开**保留确定性页面**，记账/统计/历史查询不受影响。
- **百度 OCR**：接入点 = 设置/百度 OCR + 智能录入 `/ledger/capture`。Key/Secret 掩码，测试材料默认不存为业务数据。降级：OCR 失败**可手工录入**，不影响手工记账。
- **PushPlus**：接入点 = 设置/提醒通知 + 提醒页手动发送。**通知不是后台任务**（08 §12、14 §6）：状态由页面访问确定性查询实时计算，用户确认后**同步调用**并立即写通知记录，失败可重试。降级：PushPlus 失败**保留台账内提醒**。
- **第三方 AI API**：设置/第三方 AI API 独立页，与本地 AI 分开管理，默认全关。Key 加密保存并掩码，**不能写日志**。外发前展示外发字段预览 + 脱敏 + 写审计。可一键撤销。
- **AI 工具白名单（09 §2）**：`get_dashboard_snapshot`、`analyze_assets`、`analyze_income`、`analyze_expenses`、`analyze_liabilities`、`analyze_investments`、`analyze_leases`、`search_events`、`suggest_category`、`suggest_record_from_document`、`suggest_reminder`、`create_confirmable_draft`、`apply_confirmed_suggestion`。**不能调任意 SQL/URL/文件系统，不能直接写业务表。**
- **AI 可信度标签（22 §3、07 §11）**：分析期间、基础币种、数据更新时间、记录数、已确认/草稿数、缺失数据、数据质量影响、模型类型（本地/第三方）、是否脱敏、结论类型（**事实/计算/推断/建议** 四级中文标签，不能只用颜色）。
