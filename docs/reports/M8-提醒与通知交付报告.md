# M8 · 提醒 + PushPlus + 最终安全验收 交付报告

## 1. 模块定位

M8 是《19》§3 推荐顺序的**最后一个模块**，交付后 V2.1 全部模块闭环。本模块完成：提醒中心（六类到期提醒实时计算）+ PushPlus 通知发送 + 最终安全验收。

依据文档：`08 §5 提醒通知`、`08 §12 通知发送规则`、`19 §5.7`、`22 增强建议`。

## 2. 交付内容

| 能力 | 落地 |
|---|---|
| 提醒中心 | `/ledger/reminders` 六类提醒**实时确定性计算**：还款、信用卡账单、租金到期、租约到期、资产维护、AI建议 |
| 到期识别 | 负债下次还款日按频率推算（`compute_next_payment`）；账单/租金/租约到期日；逾期（days_left<0）与临近（30 天内）标记 |
| PushPlus 发送 | `PushPlusAdapter.send()`；**手动确认同步发送**，结果立即写入通知记录 |
| 通知记录 | 新增 `notification_records` 表；发送历史、失败原因、**失败可重试**（retry_count 递增） |
| 未配置降级 | PushPlus 未配置时发送失败（记录 `failed`），**提醒照常展示，不阻塞主平台** |
| 工作台联动 | `metrics.pending_reminders` 与 `pending.reminders` 接真实提醒计数 |

## 3. 数据库 / API

- **新增 1 张表**（迁移 `0007`）：`notification_records`（渠道/类型/标题/内容/投递状态/错误/发送时间/重试次数/关联对象）。
- 新增/重写 API：
  - `GET /ledger/reminders`（六类提醒，替换占位）
  - `POST /ledger/reminders/send`（手动发送，同步）
  - `GET /ledger/notifications/records`（通知记录）
  - `POST /ledger/notifications/records/{id}/retry`（失败重试）

## 4. 关键口径（测试锁死）

1. **不建立后台调度器**（08 §12）：提醒由页面访问实时计算，非 Worker/任务队列。
2. **发送由用户手动确认**，同步发送，结果立即写记录，失败可重试（19 §5.7）。
3. **未配置 PushPlus 不阻塞**：提醒照常展示，仅发送失败（`failed` 记录）。
4. **通知不重复计账**：发送只产生通知记录，不产生业务事件/资金变动。

## 7. 已知限制

1. **AI 建议提醒当前为空**：M7 未建独立 AI 建议表（用草稿事件承载），故 `ai_suggestion` 组返回 0，如实展示。
2. **提醒无持久化"忽略/延后"状态**：提醒是实时计算的，未新增提醒表；「忽略/延后」未做持久化（需新增表，属后续增强，遵守「不得自行增加表」）。
3. **PushPlus 未实际配置**：真实推送需用户在「设置 → 提醒通知」填 Token 并启用；当前发送会记录 `failed`（设计内）。
