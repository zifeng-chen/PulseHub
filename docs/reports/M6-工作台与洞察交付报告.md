# M6 · 工作台 + 洞察 交付报告

## 1. 模块定位

M6 是《19》§3 推荐顺序的第 7 个模块，也是跨模块能力的收口：把 M1–M5 的账户、资产、负债、投资、租赁、智能录入数据，统一汇入**工作台**（一个页面回答家庭财务全景）与**洞察**（跨模块图表 + 下钻 + 数据质量中心）。

依据文档：`05 应用壳与工作台`、`07 洞察页面与图表交互`、`18 §4 模块顺序`、`19 §3`、`22 增强建议 §5`。

## 2. 交付内容

### 2.1 工作台 `/dashboard`

| 能力 | 落地 |
|---|---|
| 净资产主卡 | 账户 + 资产 + 投资 − 负债，含币种提示、多币种分组、期间变化 |
| 四指标卡 | 收入/支出/结余/待处理提醒，点击进入对应台账 |
| 图表区 | 净资产趋势、收入支出对比、账户币种结构、资产结构、负债趋势、投资持仓占比 |
| **业务摘要区（新增）** | 负债摘要（剩余本金/每月应还/逾期）、投资摘要（市值/成本/总损益）、租赁摘要（收租率/逾期/押金余额），均带跳转 |
| **图表点击下钻（新增）** | 点击图/柱/饼 → 进入对应洞察主题或台账筛选 |
| 待处理区 | AI 建议、未对账账户、临近账单、租金逾期——**未对账账户/租金逾期/临近账单已接真实计数** |
| 最近变化时间线 | 最近 8 条业务事件 |

### 2.2 洞察

| 页面 | 落地 |
|---|---|
| 综合洞察 `/insights` | 统一筛选（期间/币种/成员/投资估值）+ **7 条结论**（净资产/收入/支出/负债/资产/投资/租赁），每条含**口径、期间、数据更新时间、来源数量、查看明细、让AI继续分析** |
| 资产/收入/消费/负债/投资/租赁 六主题 | 统一 `panels` 结构（饼图/折线/柱状/统计/表格），前端通用渲染；**图表可切表格视图，不提供导出** |
| 数据质量 `/insights/data-quality` | **真实规则检查**（非盘点）：未分类流水、缺关联账户、资产缺估值、房贷未关联、车位未关联、车辆缺保险、贵金属缺字段、负债缺利率/还款方式、租金逾期、疑似重复流水；按严重/警告/提示分级，带修复跳转入口 |

### 2.3 数据质量检查规则（07 §10 落地子集）

| 检查 | 等级 | 说明 |
|---|---|---|
| 未分类流水 | 警告 | 已确认收支无分类 |
| 资金事件未关联账户 | 警告 | 收支无账户 |
| 资产缺少当前估值 | 警告 | 无价值或估值日期 |
| 不动产房贷未关联负债 | 提示 | 有房贷标记无负债记录 |
| 车位未关联不动产 | 提示 | — |
| 车辆缺少保险 | 提示 | — |
| 贵金属缺纯度/重量/估值来源 | 警告 | — |
| 负债缺利率/还款方式/到期日 | 警告 | 信用卡除外 |
| 租金应收逾期 | 警告 | 到期未实收 |
| 疑似重复流水 | 提示 | 同账户+同金额+同日+同标题 |

## 3. 数据库 / API

- **无新增表、无迁移**（M6 纯读跨模块数据，不改业务事实，符合 19 §5.9「图表表现层不改变统计数据」）。
- 新增/重写 API：
  - `GET /insights/overview`（结论列表）
  - `GET /insights/{assets,income,expenses,liabilities,investments,leases}`（六主题 panels）
  - `GET /insights/data-quality`（真实检查）
  - `GET /insights/topics`（主题清单，已标记启用）
  - `GET /dashboard/snapshot` 增强（`summaries` 业务摘要 + `pending` 真实计数）

## 4. 关键口径（测试锁死）

1. **收入分析排除内部转账/借款/押金**：转账后收入不变。
2. **每条结论必须带口径/期间/更新时间/来源数量/查看明细**（07 §1 硬要求）。
3. **数据质量非盘点、非后台任务、不修改正式数据**——修复只能跳转业务页面。
4. **图表颜色必配文字图例与数值**（前端所有饼图/柱图均带 label + legend）。
5. **图表可切表格、不提供导出**（07 §8）。

## 6. 已知限制

1. **AI 综合摘要/在线报告**：属 M7（本地 AI + 第三方 AI），当前 `ai_summary_state = module_unavailable`，页内如实展示并给「前往配置」入口。
2. **待处理提醒的「AI 建议」计数**：AI 建议模块随 M7 交付，当前为 0。
3. **固定/可变支出、商户排行、异常点**（07 §4 部分图表）：当前消费主题只交付「分类环形 + 月度趋势」，固定/可变分类与商户排行依赖更细的流水分类标注，未在本模块自造字段（遵守「不得自行增加字段」）。
4. **疑似重复流水的 `date(occurred_at)` 聚合**：在 SQLite 下全表扫描较慢，生产 MySQL 的 `DATE()` 走索引无此问题；后续大数据量时可加复合索引。
