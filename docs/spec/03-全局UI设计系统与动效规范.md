# 03 · 全局UI设计系统与动效规范

## 1. 视觉关键词

高端、克制、可信、现代、数据感。采用深色蓝黑应用壳 + 明亮内容区域；登录页采用深海蓝、曜石黑、极光青渐变；业务页保持高对比、低干扰和稳定的信息密度。

## 2.1 浅色/深色模式

系统必须支持浅色模式、深色模式和跟随系统三种选择，默认跟随系统；用户手动选择后写入个人偏好。切换主题时只过渡颜色、边框、阴影和背景，不重新加载页面、不丢失表单内容、不改变业务数据。

浅色模式：内容背景明亮，玻璃卡片使用白色高透明层，正文使用深色高对比文字。深色模式：应用壳和内容区统一深海蓝黑基底，玻璃卡片使用低透明白色层，正文使用浅色高对比文字。所有图表必须同时提供浅色和深色调色板，不能只反转背景色。

主题切换入口位于用户菜单和设置/外观设置；快捷键可选。首次启动不强制选择主题，使用默认值即可进入系统。系统检测到用户开启减少动效时，主题切换不播放大面积过渡动画。

## 3. 字体与数字

中文优先使用系统无衬线字体；数字使用等宽数字特性，金额统一使用 `MoneyText`；标题、正文、辅助文字、标签四级层级。禁止在页面中自行写颜色、圆角和间距，全部引用Token。

## 3.1 全中文界面

所有用户可见内容必须使用中文：页面标题、字段标签、占位符、按钮、菜单、状态、错误、确认提示、空状态、图表图例、Tooltip、通知、审计展示和AI操作说明。数据库字段名、API字段名、代码变量、路由和日志内部枚举可以使用英文，但不得直接暴露给用户；所有枚举必须有中文显示映射。

## 4. 应用壳

桌面宽度：左侧可折叠侧栏 240px，顶部栏 64px，内容最大宽度 1440px；侧栏折叠为 72px。移动端以 iPhone 16 逻辑视口 393×852px 为首要基准，同时适配 375—430px 宽度，不增加业务菜单。

移动端必须适配刘海和底部安全区：使用 `env(safe-area-inset-top)`、`env(safe-area-inset-bottom)`，底部导航和底部弹层不能被 Home Indicator 遮挡。横向内容不得出现非预期横向滚动，确需横向滚动的表格必须显示滚动提示。

顶部栏必须包含：页面标题、家庭名称、当前用户、全局AI按钮、通知入口、帮助/快捷键入口。

## 5. 组件交互标准

按钮：主操作一个，次操作不抢视觉；危险操作红色且二次确认。抽屉：详情和编辑优先使用右侧抽屉，复杂流程使用全屏步骤页。表格：表头固定、金额右对齐、状态用文字+颜色、支持键盘焦点。表单：字段级错误、保存中不可重复提交、离开未保存提示。

## 5.1 统一弹窗规范

所有弹窗必须使用统一 `Modal` 或 `ConfirmDialog`，禁止业务页面自行创建样式。统一结构：标题区、说明区、内容区、底部操作区；标题左对齐，右上角关闭按钮，底部按钮顺序为“取消/关闭”在左、“保存/确认”在右，危险操作使用“取消/确认删除”。

弹窗尺寸统一为小型 420px、中型 560px、大型 760px、全屏步骤页；圆角、玻璃材质、遮罩、阴影、内边距、关闭动画全部来自Token。点击遮罩是否关闭由弹窗类型决定：普通信息弹窗可关闭，未保存表单和危险确认不可通过遮罩误关闭。按 `Esc` 关闭前必须检查是否有未保存内容。

删除、冲销、停用、解除关联、启用第三方AI外发、修改基础币种等高影响动作必须使用统一二次确认弹窗，显示影响对象、影响数量、不可逆说明、操作人和必要的原因输入。

## 6. 动效原则

- 页面进入：内容整体淡入 + 上移 12px，240ms，缓动 `ease-out`。
- 卡片加载：骨架屏渐变，禁止大面积旋转加载。
- 抽屉：从右侧滑入 280ms；遮罩 160ms。
- 标签页：下划线滑动 180ms。
- 成功：图标轻微缩放和绿色高亮，300ms。
- 错误：表单区域水平抖动不超过 2 次，避免过度打扰。
- AI生成：使用细微流光、逐字出现或脉冲边框；内容完成后停止动画。
- 遵守 `prefers-reduced-motion`，减少动效时只保留状态变化。

## 7. 图表动效

折线图从左向右绘制 600ms；柱状图按序进入 450ms；环形图从 0 到目标值 500ms；悬停显示十字线、数值、单位、期间和来源；点击数据点打开对应明细；图表切换筛选时使用 300ms 平滑更新，不闪烁、不使用3D伪造数据。

## 8. 空、错、无权限状态

空状态必须告诉用户为什么为空和下一步；错误状态显示重试和技术摘要；无权限显示原因和联系管理员入口；首次使用显示配置引导，不展示虚假零数据。

## 9. 登录页视觉要求

登录页采用全屏深色渐变背景、抽象资产流动光带、玻璃拟态登录卡片、品牌标志、简短价值文案和本地部署提示。背景动画低频、轻量、不可影响输入；卡片突出邮箱/用户名、密码、记住设备、登录按钮和系统状态。
