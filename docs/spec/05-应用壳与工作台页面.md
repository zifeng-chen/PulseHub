# 05 · 应用壳与工作台页面

## 1. 应用壳 `/app`

左侧只显示四项导航：工作台、家庭台账、洞察、设置。当前项高亮并显示图标和文字；家庭台账展开二级菜单时不算新增一级菜单。右上角显示全局AI、提醒、用户菜单。

### 导航选中状态硬规则

菜单选中状态必须由当前路由实时计算，不能在组件初始化时固定第一个菜单为选中，也不能使用独立的永久 `activeIndex = 0`。路由元数据必须声明所属一级菜单和二级页面：`/dashboard` → 工作台，`/ledger/**` → 家庭台账，`/insights/**` → 洞察，`/settings/**` → 设置。

进入深层页面、浏览器刷新、直接输入URL、前进/后退、登录跳转和从AI来源跳转后，一级菜单都必须根据当前路由重新计算。家庭台账内部页切换时只保持“家庭台账”一级菜单选中，并高亮对应二级页。不存在匹配路由时不得错误选中第一个菜单。

导航测试必须覆盖：从设置进入第三方AI配置后设置保持选中；从资产详情进入洞察后洞察选中；刷新负债页面后家庭台账选中；从登录页进入工作台后工作台选中；移动端底部导航和桌面侧栏选中结果完全一致。

用户菜单：个人资料、快捷键、锁定屏幕、退出登录。退出需清除本地会话缓存但不清除业务数据。

### 移动端应用壳

在 393×852px 基准下，桌面侧栏隐藏，使用底部四项导航：工作台、家庭台账、洞察、设置；底部导航固定在安全区上方，图标和中文名称同时显示。家庭台账内部页使用顶部横向页签或二级抽屉，不把内部页变成底部导航。

移动顶部栏显示当前页面中文标题、全局AI按钮和提醒入口；用户菜单进入全屏底部抽屉。所有点击区域最小 44×44px。

## 2. 工作台 `/dashboard`

### 页面目标

在一个页面回答：家庭现在有多少净资产、钱从哪里来、花到哪里去、负债压力如何、哪些事项需要处理。

### 布局顺序

1. 页面标题、期间选择、基础币种、刷新、AI摘要按钮。
2. 净资产主卡：总资产、总负债、净资产、较上一期间变化、币种提示。
3. 四个指标卡：本期收入、本期支出、本期结余、待处理提醒。
4. 图表区：净资产趋势、资产结构、收入支出对比。
5. 业务摘要区：负债、投资、租赁。
6. 待处理区：AI建议、未对账账户、临近账单、租金逾期。
7. 最近变化时间线。

### 交互

时间范围改变时所有卡片和图表同步刷新；点击数字进入对应台账筛选；点击图表点进入该日期明细；点击AI摘要打开右侧助手并带入当前期间；刷新按钮显示最近计算时间。

### 状态

首次无数据：显示配置账户和新增第一笔记录的双入口；部分数据：明确“统计不完整”并列缺失对象；模型不可用：工作台统计继续显示，AI摘要显示未连接；接口失败：局部卡片独立错误，不让整页空白。

### 动效

首屏卡片依次淡入，数字使用短时滚动计数但最终以服务端字符串为准；图表按统一动效规范进入；待处理卡片出现时使用一次柔和强调，不循环闪烁。

移动端卡片按单列排列；指标卡可横向滑动但必须显示分页提示；图表优先单列并支持触摸查看；详情抽屉改为底部全屏面板；表格改为信息卡片，保留关键字段和操作入口。

## 3. 全局AI侧栏

从任何页面打开，宽度 420px，展示会话标题、当前数据上下文、输入框、推荐问题、回答、来源、建议操作。侧栏打开不改变当前页面筛选；关闭后会话保留。高影响建议必须打开确认卡，不允许在流式回答中直接执行。
