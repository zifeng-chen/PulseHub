# 09 · 本地AI全项目交互规格

## 1. AI定位

本地AI是跨页面的分析和辅助层，不是权威数据源，不是自动交易员，不是后台任务执行器。它只能通过后端白名单工具读取确定性统计结果和授权明细。

## 2. AI工具

`get_dashboard_snapshot`、`analyze_assets`、`analyze_income`、`analyze_expenses`、`analyze_liabilities`、`analyze_investments`、`analyze_leases`、`search_events`、`suggest_category`、`suggest_record_from_document`、`suggest_reminder`、`create_confirmable_draft`、`apply_confirmed_suggestion`。

AI不能调用任意SQL、任意URL、任意文件系统，不能直接写业务表，不能转账、删除、下单或自动发送高影响通知。

## 3. 上下文规则

每次请求携带：当前路由、实体ID、筛选期间、币种、家庭范围、用户权限、数据更新时间。上下文条在UI中可见，用户可以清除当前上下文后重新提问。

## 4. 页面场景

| 页面 | 推荐问题 | 输出 |
|---|---|---|
| 工作台 | 净资产为什么变化？ | 变化来源和事件明细 |
| 资产 | 哪类资产占比最高？ | 结构、集中度、估值缺口 |
| 流水 | 本月消费增加在哪里？ | 分类、商户、期间对比 |
| 账户 | 余额和流水对不上吗？ | 疑似漏记、重复、对账建议 |
| 负债 | 下月还款压力如何？ | 本金、利息、到期和现金流 |
| 投资 | 哪些持仓变化最大？ | 成本、市值、损益、占比 |
| 租赁 | 哪些租金逾期？ | 应收、实收、逾期和提醒草稿 |
| 智能录入 | 识别这张账单 | OCR清洗、分类和待确认事件 |
| 洞察 | 给我一份家庭财务分析 | 带口径、证据和建议的在线报告 |

## 4.1 全页面AI覆盖矩阵

| 页面 | AI是否接入 | AI职责 | 禁止事项 |
|---|---:|---|---|
| 安装检测/首次启动 | 是 | 检查接入状态、解释配置项、提供配置提示 | 不读取业务数据、不替用户设置密钥 |
| 登录/密码 | 是 | 解释登录错误和安全提示 | 不读取密码、不判断或修改密码 |
| 工作台 | 是 | 综合摘要、趋势、异常、行动建议 | 不直接修改指标 |
| 台账总览 | 是 | 当前家庭账务概况和待处理建议 | 不绕过权限 |
| 资产列表/详情/估值 | 是 | 资产结构、估值缺口、集中度 | 不自动改估值、处置资产 |
| 账户列表/详情 | 是 | 现金流、余额异常、账户使用分析 | 不直接调余额 |
| 流水列表/收入支出/转账 | 是 | 分类、重复、异常、自然语言检索 | 不自动确认流水、转账 |
| 对账 | 是 | 差异解释、疑似漏记和重复提示 | 不自动调整余额 |
| 负债/还款 | 是 | 偿付压力、利息、到期和还款构成 | 不发起支付、不改本金 |
| 信用卡账单/还款 | 是 | 消费构成、账单解释、还款压力 | 不重复计消费、不自动还款 |
| 投资账户/持仓/交易 | 是 | 成本、市值、损益、集中度 | 不下单、不自动估值 |
| 房产/租约/收租/押金 | 是 | 收租率、逾期、合同和押金分析 | 不自动催收、不混淆押金收入 |
| 智能录入/OCR | 是 | OCR清洗、字段补全、分类和事件草稿 | 不把低置信度内容直接入账 |
| 提醒 | 是 | 提醒建议、内容草稿、来源解释 | 不建立后台任务、不自动高影响发送 |
| 洞察各主题 | 是 | 资产、收入、消费、负债、投资、租赁报告 | 不编造数据、不作自动投资决策 |
| 设置/用户管理 | 是 | 解释权限、配置项、接入状态和安全风险 | 不自动提权、改密钥或改权限 |

## 5. 输出类型与确认

只读回答直接显示；分析显示证据；分类/字段补全/事件/提醒进入建议卡；建议卡必须显示接受、修改、拒绝。接受时后端再次检查权限、版本、金额和源数据，事务成功后才更新正式台账。

## 5.1 AI调用优先级

每次调用按“权限检查 → 确定性工具 → 本地AI → 可选第三方AI”顺序执行。第三方AI只有在设置中显式启用、隐私策略允许、外发预览通过并写入审计后才可调用。任何模型都不能绕过确定性统计工具自行计算权威金额。

## 6. AI状态

模型流式输出期间显示停止按钮；超时显示重试；模型断开时保留确定性页面；结果解析失败不创建建议；数据不足显示缺少对象和补录入口；敏感字段被脱敏时在回答中标记数据范围受限。

## 7. AI动画

等待工具时显示“正在读取统计数据”；模型生成时显示轻量流光；工具失败显示静态错误状态；建议生成完成后出现一次边框高亮；禁止无限旋转、自动弹窗和持续闪烁。
