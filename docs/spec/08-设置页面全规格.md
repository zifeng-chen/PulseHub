# 08 · 设置页面全规格

## 1. 设置首页 `/settings`

展示配置完整度、管理员/家庭信息、AI连接状态、OCR状态、通知状态、分类数量、主题模式入口、审计入口。每张状态卡可进入对应设置，不在首页直接编辑敏感凭证。

## 1.1 外观设置

提供浅色、深色、跟随系统三个选项；显示实时预览；切换后立即应用并保存到当前用户偏好；图表、玻璃面板、弹窗和文字同时切换；不刷新页面、不丢失表单、不影响数据请求。

## 2. 家庭与成员 `/settings/household`

家庭信息：名称、基础币种、时区、描述。成员列表：名称、账号、角色、状态、最近登录、授权范围、创建时间、最后修改人。邀请/新增成员、停用、重置密码、调整角色均需权限和二次确认。

用户管理必须包含四个区域：用户列表（搜索、角色筛选、状态筛选、最近登录、逐项停用）、用户详情（基本资料、角色、家庭范围、可查看成员范围、可操作业务范围、登录设备和审计记录）、用户编辑（姓名、头像、账号、手机号/邮箱、角色、启用状态、数据权限）和会话管理（设备、IP摘要、登录时间、撤销单个或全部会话）。用户管理页面的AI只负责解释权限和生成操作提示，不得自动新增、停用、提权或重置密码。

## 3. 分类管理 `/settings/categories`

按分类域切换：收入、支出、资产、负债、投资、租赁。支持新建、编辑、启用、停用、排序、父子层级；已被业务事件使用的分类不能物理删除。显示“AI是否可推荐”开关和适用事件类型。

## 4. 财务口径 `/settings/finance`

配置基础币种、统计周期、资产购置展示口径、投资估值是否纳入净资产、默认日期范围、金额精度展示。所有配置变更显示影响说明并写审计。

## 5. 提醒通知 `/settings/notifications`

通知渠道卡：PushPlus Token、启用、测试、最近发送状态。提醒类型开关：还款、信用卡账单、租金到期、租约到期、资产维护、AI建议。通知失败不影响台账内提醒。

## 6. 百度OCR `/settings/ocr`

字段：API Key、Secret Key、区域/接口配置、启用、测试识别、最近调用、错误说明。所有密钥掩码；测试材料不得默认保存为业务数据。OCR状态只影响智能录入，不影响手工记账。

## 7. 本地AI `/settings/local-ai`

字段：协议、地址、模型名、API Key（如需要）、请求超时、上下文长度、流式输出、启用开关。状态：未配置、检测中、已连接、模型不可用、权限失败、超时。测试返回模型名、延迟、上下文支持和最近时间。默认不连接云端。

## 8. 第三方AI API `/settings/ai-providers`

第三方AI API与本地AI分开管理。支持OpenAI兼容接口、企业内部兼容接口和其他自部署兼容服务，默认全部关闭。

配置字段：提供商名称、接口类型、Base URL、API Key、组织/项目标识、默认模型、备用模型、超时、最大输入/输出长度、流式开关、是否允许附件、是否允许敏感字段、启用状态、调用优先级。

页面功能：新增、编辑、启停、连接测试、模型能力测试、查看文本/视觉/结构化输出能力、设置优先级、查看错误、查看外发字段预览、查看调用审计和一键撤销配置。API Key加密保存并掩码显示，不能写入日志。

调用规则：本地AI优先；仅当用户显式启用第三方AI、隐私策略允许、外发预览通过并写入审计后才可调用。本地AI失败时不能静默切换第三方API。

## 9. 隐私与安全 `/settings/privacy`

配置本地文件保留时间、AI会话保留时间、敏感字段脱敏、云端外发总开关、外部调用审计。云端AI总开关默认为关闭，打开时必须二次确认并展示外发字段。

## 10. 系统状态与审计 `/settings/system`

显示应用版本、数据库连接、迁移版本、文件存储、OCR、本地AI、第三方AI、通知状态。审计按时间、操作者、对象、提供商、调用类型和动作筛选，提供前后摘要，不显示密钥和完整敏感字段。

审计详情必须支持查看：操作时间、操作人、用户角色、家庭、IP摘要、会话ID、请求ID、动作名称、对象类型、对象ID、关联对象ID、来源页面、来源方式（手工/OCR/AI/API）、变更前快照摘要、变更后快照摘要、字段级差异、原因、结果、错误码、耗时、外部提供商、脱敏情况。敏感值只显示掩码，技术堆栈仅管理员在故障详情中查看。

删除、冲销、停用、解除关联和配置变更必须记录完整审计；日志本身只允许追加，不允许用户编辑或删除。审计列表提供中文动作名称和中文对象名称，不直接显示内部英文枚举。

## 11. 数据备份与恢复 `/settings/backup`

数据备份不是导出功能，用于本地灾备和版本升级恢复，不生成供用户传播的报表文件。

备份内容包括：MySQL业务数据、系统配置、用户/权限配置、分类、AI/OCR/通知配置的加密密文、审计记录、附件索引和附件文件。密码、Token和Secret只能以加密密文保存，恢复时不能显示明文。

页面显示最近备份时间、备份大小、完整性、数据库版本、应用版本、附件数量和恢复点。支持手动创建备份、完整性验证、恢复预览、恢复执行、删除旧备份和设置本地保留数量；每个操作都需要二次确认。

恢复流程：选择恢复点 → 显示应用版本、数据库版本、数据时间和影响范围 → 输入确认短语 → 确认备份 → 进入维护锁定 → 恢复数据 → 校验迁移版本和关键表 → 记录恢复审计 → 重新登录。恢复失败必须保留原数据或回滚到恢复前快照，不能半恢复运行。

不建设后台备份任务、Worker或任务队列。备份由管理员手动触发或由外部部署系统调用明确接口触发，页面显示备份状态和失败原因。

## 12. 通知发送规则

提醒状态由页面访问和确定性查询实时计算；本项目不建立后台调度器、Worker或任务队列。通知发送由用户在提醒页面手动确认，或在确认业务事件/确认提醒时同步发送。结果立即写入通知记录，失败可重试。
