# 01 · 产品范围与技术基线

## 1. 产品定位

FAM 是一个本地优先的家庭资产与财务智能分析平台。它将家庭成员、资产、账户、收入、消费、负债、信用卡、投资、房产租赁和提醒统一为可追溯的家庭财务事实，并由本地 AI 在权限范围内进行解释和分析。

## 2. 四类用户

| 用户 | 能力 |
|---|---|
| 系统管理员 | 首次启动创建，配置系统连接、家庭和管理员设置 |
| 家庭所有者 | 管理家庭、成员、权限、业务数据、AI和通知配置 |
| 家庭成员 | 查看和维护被授权的家庭数据 |
| 只读成员 | 只能查看授权数据和AI分析，不得写入 |

## 3. 功能边界

包含：登录、首次启动引导、家庭成员、资产、账户、流水、对账、负债、信用卡、投资、房产、租赁、提醒、智能录入、百度OCR、本地AI、PushPlus、工作台、洞察、设置、审计。

不包含：盘点、库存、位置、导出、后台任务、异步队列、自动交易、自动转账、云端AI默认调用。

## 4. 核心数据口径

- 净资产 = 可计入资产当前价值 + 投资当前市值 - 负债未偿余额。
- 收入只包含已确认收入、投资收入、租金实收；借款、押金、内部转入不算收入。
- 支出只包含已确认消费、利息、手续费等；信用卡还款和贷款本金不重复计入支出。
- 内部转账只改变账户余额，不改变收入和支出。
- 资产购置形成资产和资金减少，是否计入消费由事件口径显示区分，不得双计。
- 应收、计划、账单和草稿不等于实际发生。
- 多币种按币种分组，只有用户确认汇率和换算规则后才能生成换算结果。

## 5. 技术基线

前端：Vue3、TypeScript、Vite、Vue Router、Pinia、ECharts、Lucide。后端：FastAPI、Pydantic、SQLAlchemy Async、Alembic。数据库：MySQL 8.x。部署：本地优先，支持 Docker Compose，但不强制引入 Redis、MQ、ES或独立向量数据库。

## 6. 工程原则

单一事实源、后端确定性统计、事务保证一致、组件统一复用、页面状态完整、AI可解释可审计、配置可测试、敏感信息加密、所有高影响动作二次确认。
