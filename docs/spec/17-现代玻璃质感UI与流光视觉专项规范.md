# 17 · 现代玻璃质感UI与流光视觉专项规范

## 1. 视觉目标

FAM V2.1 采用“深海蓝黑应用壳 + 半透明玻璃面板 + 极光流光高光 + 明亮数据内容区”的现代化视觉。玻璃效果用于层级和重点信息，不把所有元素都做成透明，避免信息模糊和低可读性。

关键词：现代、精致、克制、可信、玻璃拟物、流光、数据感、轻交互。

## 2. 页面背景层

应用背景由四层组成：

1. 基础底色：浅色业务区 `#F4F7FC`，深色壳体 `#0A1222`。
2. 大面积径向光晕：蓝色、紫色和青色，透明度不超过 20%。
3. 细微噪点纹理：透明度 2%—4%，防止渐变出现色带。
4. 内容玻璃层：根据组件级别使用不同透明度和模糊值。

背景光晕只做装饰，不能影响文字、点击、滚动和表格性能。

浅色和深色模式共用玻璃层级逻辑，但必须使用两套完整Token，不能通过简单反色实现。浅色模式强调白色高光和浅蓝背景；深色模式强调深蓝底色、低透明白玻璃和蓝紫光晕。主题切换使用 180—240ms 的颜色过渡，关闭减少动效后立即切换。

## 3. 玻璃层级Token

### 3.1 深色玻璃

```text
glass-dark-1: rgba(255,255,255,.06)
glass-dark-2: rgba(255,255,255,.10)
glass-dark-3: rgba(255,255,255,.15)
glass-dark-border: rgba(255,255,255,.16)
glass-dark-highlight: rgba(255,255,255,.28)
glass-dark-blur: 20px
```

### 3.2 浅色玻璃

```text
glass-light-1: rgba(255,255,255,.56)
glass-light-2: rgba(255,255,255,.72)
glass-light-3: rgba(255,255,255,.86)
glass-light-border: rgba(255,255,255,.72)
glass-light-highlight: rgba(255,255,255,.96)
glass-light-blur: 18px
```

### 3.3 玻璃边框与阴影

```text
glass-border: 1px solid rgba(255,255,255,.46)
glass-inner-highlight: inset 0 1px 0 rgba(255,255,255,.72)
glass-shadow: 0 12px 40px rgba(30,55,105,.10)
glass-shadow-heavy: 0 24px 80px rgba(8,22,55,.22)
glass-radius-card: 20px
glass-radius-panel: 24px
glass-radius-control: 12px
```

## 4. 流光玻璃效果

流光使用独立装饰层，不改变业务内容。装饰层采用蓝—紫—青的低透明度线性渐变，沿卡片边缘或背景缓慢移动，周期 8—14 秒，使用 `ease-in-out`，不无限提高亮度。

规则：

- 登录页主视觉允许 2 条大流光带。
- AI面板、重要统计卡允许 1 条细流光边。
- 普通表格、表单、设置页不持续流光，只在进入或成功状态短暂显示。
- 鼠标靠近卡片时可产生轻微高光偏移，但偏移不超过 12px。
- 任何流光都必须 `pointer-events: none`，不得遮挡文字和控件。
- `prefers-reduced-motion` 时关闭移动流光，只保留静态渐变边框。

## 5. 应用壳

左侧导航使用深色玻璃：背景透明度 10%—15%，背景模糊 24px，激活项使用蓝紫渐变玻璃块、左侧 3px 高亮条和轻微内阴影。顶部栏使用半透明深色玻璃，滚动时增加边框和阴影，不改变高度。

内容区使用明亮底色，工作台卡片使用浅色玻璃。四项一级菜单始终保持清晰，玻璃层不能让导航文字和背景混在一起。

## 6. 组件材质规范

### 6.1 统计卡

背景使用 `glass-light-2`，圆角 20px，顶部内高光；重要卡片右上角增加极淡的光晕。金额使用深色等宽数字，变化值用文字和图标共同表达。悬停上移 2px，阴影加深，不放大内容。

### 6.2 按钮

主按钮使用蓝紫渐变实体玻璃，悬停增加顶部高光，按下缩小 1%，禁用降低透明度但保留文字对比度。次按钮使用透明玻璃边框。危险按钮不使用炫目的流光，使用稳定的红色边框和明确文字。

### 6.3 输入框

默认使用浅色半透明底、1px玻璃边框；聚焦时显示蓝色外发光环和顶部高光，不改变布局。密码框、Token、证件号等敏感字段使用独立遮罩和显示/隐藏按钮。

### 6.4 抽屉与弹窗

抽屉主体使用 `glass-light-3` 或 `glass-dark-3`，背景模糊 28px，边缘有 1px 高光；遮罩使用 rgba(5,15,35,.36)。高影响确认弹窗不使用强流光，必须优先保证阅读和确认。

### 6.5 表格

表格外壳可以使用玻璃面板，但表格行不使用过强透明叠加。表头固定、背景略深；悬停行使用 rgba(primary,.06)；选中行使用左侧高亮条。金额、状态、来源和操作必须清楚可读。

### 6.6 AI面板

AI面板使用紫蓝玻璃材质，顶部有细流光线；模型生成时显示小范围脉冲，不让整个面板闪烁。回答、来源、建议确认卡使用不同层级的玻璃，建议卡必须有明确的接受/修改/拒绝按钮。

### 6.7 通知与提醒

通知入口使用玻璃徽标；有未处理事项时只显示一次轻微呼吸动画。提醒列表使用状态色和图标，不使用持续闪烁。

### 6.8 统一弹窗

所有页面的弹窗统一使用相同的玻璃材质、遮罩强度、圆角、标题层级、按钮位置和进入/退出动画。普通弹窗使用中性玻璃；危险确认弹窗使用稳定的红色边框和少量红色高光，不使用流光装饰掩盖风险。删除确认必须明确显示“将删除/停用/冲销的对象”和“此操作是否可恢复”。

## 7. 登录页专项

登录页为全屏深色玻璃空间：背景是深海蓝渐变、模糊光球、两条缓慢流光；登录卡使用深色玻璃、24px模糊、1px亮边、内高光和重阴影。品牌标识使用极光青小范围光晕。

输入焦点采用蓝紫外发光；登录按钮在提交时显示流光从左向右移动，成功时卡片轻微缩小并淡出；失败时只对输入区域做一次短暂水平位移。动画不能阻塞键盘输入。

## 8. 首次启动引导

引导页面使用浅色玻璃步骤卡，左侧步骤导航为半透明玻璃，当前步骤有蓝紫高亮。数据库测试、管理员创建、AI/OCR/通知测试结果均使用状态徽标和清晰文本，不能只用颜色。成功步骤出现短暂高光扫过，失败步骤使用红色边框和修复说明。

## 9. 图表视觉

图表容器使用浅玻璃卡片；图表本体保持高对比，不给每条线增加模糊。重点数据使用渐变填充和极细高光；悬停时显示玻璃Tooltip，包含数值、币种、时间、来源和明细入口。点击数据点有短暂涟漪反馈并打开关联明细。

## 10. 页面级应用

| 页面 | 玻璃重点 |
|---|---|
| 工作台 | 净资产主卡、AI摘要卡、待处理卡使用三种玻璃层级 |
| 家庭台账 | 页面容器和详情抽屉玻璃，表格保持清晰不透明过度 |
| 智能录入 | 文件预览、OCR文本和AI建议使用三列不同层级玻璃 |
| 洞察 | 图表卡、AI报告卡、来源抽屉使用玻璃层级 |
| 设置 | 状态卡和配置卡玻璃，敏感字段保持清晰遮罩 |
| 登录 | 全屏深色玻璃和主登录卡使用最强视觉效果 |

## 11. 性能和降级

`backdrop-filter`不可用时，使用不透明的近似背景色、边框和阴影替代；低性能设备减少背景光晕、噪点和流光层；图表和表格不得因为玻璃效果掉帧。装饰动画必须使用 `transform` 和 `opacity`，避免频繁触发布局。

## 12. 可读性与无障碍

玻璃透明度不能降低正文、金额、表头和错误提示的对比度；所有状态必须同时使用文字、图标或形状；Tooltip不能成为唯一信息来源；键盘焦点必须有清晰外框；系统减少动效时关闭流光移动和数字滚动，但不隐藏信息。

浅色和深色模式下均须通过文字对比度检查；不能只用颜色区分收入/支出、成功/失败和权限状态。所有可见字段使用中文名称，英文技术标识不得出现在普通用户界面。

## 13. 视觉验收

- 登录页、工作台、台账、洞察、设置均体现统一玻璃材质，但层级有差异。
- 流光只作为装饰，不遮挡文字，不影响点击和输入。
- 所有卡片、抽屉、表格、按钮、输入框、AI面板有明确默认/悬停/聚焦/禁用/错误/成功状态。
- 图表具有动画、玻璃Tooltip、悬停、点击下钻和表格摘要。
- 关闭动效或浏览器不支持模糊时页面仍然可用且可读。
