# 11 · 状态机、异常与交互规则

## 1. 页面通用状态

每个页面和接口都必须覆盖：初始、加载、成功、空数据、部分数据、校验失败、无权限、网络失败、服务失败、提交中、提交成功、提交失败、离开未保存。

## 2. 业务状态

业务事件：`draft -> confirmed -> reversed`，或 `draft -> cancelled`；确认后不能直接编辑关键金额。

AI建议：`pending -> accepted/rejected/expired`，终态不可重复操作。

资产：`active -> disposed/archived`；处置后不进入当前资产总值。

负债：`active -> overdue -> settled`；结清后历史保留。

租约：`draft -> active -> expired/terminated`。

提醒：`pending -> completed/snoozed/dismissed`；通知发送单独记录 `pending/sent/failed`，不是后台任务。

文件：`uploaded -> scanning -> ready/failed`；失败可重试，不进入正式业务事实。

## 3. 异常规则

401跳转登录；403显示权限范围；404显示对象不存在；409显示数据已变化并要求刷新；422显示字段错误；429显示稍后重试；AI超时保留页面并提供重试；OCR失败可手工录入；通知失败保留台账内提醒。

## 4. 防重复

按钮提交期间锁定；服务端幂等键；刷新不重复创建；接受AI建议前检查建议状态；批量操作逐项返回结果；上传相同文件提示可能重复但不自动删除。

## 5. 危险动作

所有删除、冲销、停用成员、删除分类、解除资产关联、修改基础币种、启用云端外发、接受影响多条记录的AI建议，必须统一使用二次确认弹窗，显示影响范围、是否可恢复、操作原因和审计说明。已确认业务事实不物理删除，只能冲销或更正；可删除的草稿、附件和配置也必须二次确认并记录审计。

## 6. 键盘与无障碍

所有可操作元素可键盘访问；焦点不丢失；弹窗打开后焦点进入弹窗，关闭后回到触发按钮；颜色外必须有文字或图标；图表提供表格摘要；减少动效时所有信息仍可理解。

## 7. 路由与导航状态

导航激活状态是路由派生状态，不是独立业务状态。任何路由变化都必须触发导航重新计算；应用启动时先等待路由解析，再渲染选中状态，禁止默认第一个菜单短暂或永久选中。路由不存在、权限不足和重定向时，导航状态必须以最终有效路由为准。

## 8. 移动端交互状态

以 iPhone 16 393×852px 为基准验证：底部导航安全区、横向滚动表格、底部抽屉、软键盘顶起表单、图表触摸Tooltip、AI输入框、上传文件和弹窗关闭。软键盘打开时输入框必须保持可见；底部导航不能覆盖提交按钮。
