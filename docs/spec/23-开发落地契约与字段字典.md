# 23 · 开发落地契约与字段字典

本文件把前面的产品文档转换为开发阶段必须遵守的工程契约。开发AI不得用页面猜字段、用接口猜状态、用模型猜统计口径。

## 1. 统一API响应

成功响应：

```json
{
  "success": true,
  "data": {},
  "request_id": "请求编号",
  "message": "操作成功"
}
```

失败响应：

```json
{
  "success": false,
  "error": {
    "code": "业务错误码",
    "message": "中文错误说明",
    "field_errors": {},
    "retryable": false,
    "request_id": "请求编号"
  }
}
```

列表响应必须包含：`items`、`total`、`page`、`page_size`、`has_next`、`request_id`。金额和数量全部以字符串返回，时间使用ISO 8601。

## 2. 通用字段

所有业务实体至少有：编号、家庭编号、创建时间、更新时间、创建人、修改人、数据版本、删除时间。用户可见时统一转换为中文标签；编号不展示给普通用户或只显示短编号。

所有写接口必须支持幂等编号；更新接口必须带数据版本；版本冲突返回409；删除接口不代表物理删除。

## 4. 统一业务事件字段

业务事件必须支持：事件编号、事件类型、状态、发生时间、确认时间、金额、币种、汇率、分类、账户、成员、资产、负债、投资账户、租约、标题、商户/对方、来源、附件、备注、版本。

事件确认前是草稿，不进入余额、净资产、收支、洞察或AI权威分析。确认事件必须在同一事务中生成资金变动和审计记录。

## 5. 资产字段最小契约

通用资产：名称、类型、子类型、持有人、购买日期、购买成本、当前估值、估值日期、估值来源、币种、状态、是否计入净资产、关联账户、关联负债、附件。

不动产：产权证号、不动产权证号、地址文本、建筑面积、套内面积、土地面积、购买日期、购买总价、装修费用、税费、共有比例、房贷关联、出租状态、水电煤户号。

车位：产权/使用权类型、编号、面积、购买日期、购买价格、当前估值、管理费、关联不动产编号。

车辆：品牌、车系、车型、VIN、车牌、发动机号、购买日期、上牌日期、购买价格、当前估值、里程、能源类型、贷款、保险、费用流水。

贵金属：品类、形式、品牌、证书编号、购买日期、纯度、重量、单位、购买单价、加工费、税费、当前单价、当前估值、估值来源、批次。

## 6. 权限动作矩阵

权限必须拆成“查看、创建草稿、编辑草稿、确认、冲销、更正、归档、删除、配置、审计查看”十类动作。角色只拥有动作集合，成员范围再限制对象范围。

| 动作 | 所有者 | 管理员 | 普通成员 | 只读成员 |
|---|---:|---:|---:|---:|
| 查看 | 是 | 是 | 按范围 | 按范围 |
| 创建草稿 | 是 | 是 | 可配置 | 否 |
| 确认事实 | 是 | 是 | 可配置 | 否 |
| 冲销/更正 | 是 | 是 | 可配置 | 否 |
| 配置提供商 | 是 | 可配置 | 否 | 否 |
| 管理用户 | 是 | 可配置 | 否 | 否 |
| 查看审计 | 是 | 可配置 | 否 | 否 |

后端每次请求同时校验用户、家庭、对象、动作和成员/资产范围。

## 8. AI工具契约

每个AI工具必须声明：工具名称、中文名称、输入字段、权限要求、数据范围、返回字段、是否可生成建议、是否允许写草稿、禁止动作、失败码和来源字段。

工具返回必须包含：分析期间、币种、数据更新时间、记录数量、数据质量提示、来源对象列表和结构化结果。模型只能解释工具返回，不能自行拼接权威金额。

接受AI建议的接口不是模型直接写入，而是用户确认后由领域服务执行；执行前重新检查权限、版本、幂等编号和源数据。

## 9. 字段校验

金额必须大于等于零，退款和冲销使用事件类型表达正负关系；日期不能晚于允许的业务范围；利率使用明确百分比单位；面积、重量、数量不能使用负数；证件号、VIN、车牌、户号和Token按敏感字段处理；必填字段依据资产类型动态校验。

## 10. 统计查询契约

统计接口必须接收期间、币种、成员范围、是否包含草稿（默认否）和数据版本；返回统计口径、参与记录数、排除记录数、数据质量提示和更新时间。前端不自行计算净资产、余额、损益或汇总金额。

## 11. 开发完成定义

页面存在不等于完成。只有字段、接口、迁移、权限、关联、统计、AI、主题、中文、移动端、审计、二次确认和测试全部完成，模块才可以标记为完成。
