## 2. 统一领域关系

```mermaid
flowchart TD
  HH[家庭] --> MEM[成员]

  HH --> PROP[房产/租约]
  HH --> CAT[分类]
  HH --> EVT[业务事件]
  EVT --> MOV[资金变动]
  MOV --> ACC
  MOV --> AST
  MOV --> LIAB
  MOV --> INV
  MOV --> PROP
  AST --> VAL[估值]
  LIAB --> REP[还款]
  INV --> TRADE[交易]
  PROP --> RENT[应收/实收/押金]
  EVT --> ATT[附件]

  OCR --> AIS[AI建议]
  AIS -->|用户确认| EVT
  EVT --> STATS[确定性统计]
```

资产类型的房产主对象统一使用 `real_estates`；房产租赁页面中的“房产”直接引用该对象，不再另建一套 `properties` 主数据。资产类型扩展关系如下：

```mermaid

  CARLOAN --> LIABILITY

  COST --> EVENT
  METALTX --> EVENT
```

## 3. 页面与数据关联

| 页面 | 读取 | 写入 | AI上下文 |
|---|---|---|---|
| 工作台 | 统计快照、提醒、最近事件 | 无或跳转草稿 | 家庭综合财务 |
| 台账总览 | 全部已确认统计 | 无 | 当前家庭摘要 |
| 资产 | 资产、估值、购置/处置事件 | 资产、估值草稿 | 当前资产与净资产占比 |
| 账户流水 | 账户、事件、资金变动、分类 | 事件/转账/对账 | 当前账户和期间流水 |
| 负债 | 负债、还款、账单 | 负债/还款草稿 | 偿付压力和到期 |
| 投资 | 投资账户、交易、持仓、估值 | 交易/估值草稿 | 持仓、成本和收益 |
| 租赁 | 房产、租约、应收、实收、押金 | 租约/收租/押金草稿 | 收租率和逾期 |
| 智能录入 | 附件、OCR、建议 | 草稿、建议反馈 | 文件内容和历史模式 |
| 提醒 | 到期规则、提醒、发送记录 | 提醒草稿/确认 | 可提醒事项 |
| 洞察 | 只读统计视图 | AI洞察快照 | 跨模块分析 |
| 设置 | 配置和状态 | 配置、成员、分类、审计 | 接入状态，不直接分析业务 |

## 4. 统一写入链路

```mermaid
sequenceDiagram
  participant UI as 页面
  participant API as 领域API
  participant V as 校验服务
  participant E as 事件服务
  participant S as 统计服务
  participant AI as AI服务
  UI->>API: 表单/建议确认
  API->>V: 权限、字段、版本、币种校验
  V->>E: 创建或确认业务事件
  E->>S: 更新可查询统计
  S-->>UI: 业务结果
  UI->>AI: 可选请求解释
  AI-->>UI: 带来源的分析结果
```

## 5. 全局返回关系

所有列表行、图表点、AI结论、提醒卡和统计卡都必须提供“查看来源”或“查看明细”路径，最终定位到家庭台账内的实体详情或事件详情。
