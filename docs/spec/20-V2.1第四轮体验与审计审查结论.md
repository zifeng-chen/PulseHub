## 3. 中文字段执行口径

“字段全中文”指所有用户可见内容必须中文，包括页面、表单、按钮、状态、错误、图表、通知、审计和AI操作。数据库字段、API字段、代码变量、路由和内部枚举可以保留英文技术标识，但必须通过中文显示映射，不能直接显示给普通用户。

## 4. 详细日志最低字段

每次重要操作至少记录：请求ID、时间、操作人、角色、家庭、会话摘要、IP摘要、来源页面、来源方式、动作、对象类型、对象ID、关联对象ID、变更前摘要、变更后摘要、字段级差异、操作原因、结果、错误码、耗时、外部提供商、脱敏状态。敏感值只记录掩码；技术堆栈限制管理员查看；审计记录只允许追加。

## 5. 删除规则

所有删除、冲销、停用、解除关联和高影响修改都必须弹出统一确认框。已确认业务事实不物理删除，只能冲销或更正；草稿、附件、配置和分类也必须二次确认。确认请求必须携带一次性确认令牌，后端再次校验对象版本、权限和幂等键。

## 6. 统一弹窗规则

所有模块只允许使用统一弹窗组件。弹窗必须统一标题、内容、按钮顺序、圆角、玻璃材质、遮罩、焦点、键盘关闭、未保存提示和动画。危险操作的确认按钮固定使用明确中文动作，例如“确认删除”“确认停用”“确认冲销”，不能使用模糊的“确定”。

## 7. 本轮最终结论

当前文档已不仅定义业务功能，也定义了主题系统、视觉材质、中文交互、安全审计和模块交付方式。后续开发应先做 M0 框架基座，并把主题、中文、弹窗、审计和删除确认作为基座验收项；用户验收 M0 后再逐模块推进。
